Who built Sley?

Sley is developed by Greyforge Labs. The public domain chain is sleylang.org with the broader Greyforge context on greyforge.tech.

Is Sley open source?

Yes. The repository is public and released under Apache-2.0 at github.com/GreyforgeLabs/sley.

Why call it “AI-native”?

Sley is built for agent workflows where code intent can be represented as bounded structure instead of full-text guesswork. It focuses on token-efficient language behavior, reduced drift, and reviewable transitions.

What are current public limits?

This site intentionally publishes a constrained public brief. Some internals remain private for safety and ongoing hardening.

Does Sley execute external systems by default?

Sensitive host paths are explicit and controlled. Live external behavior is not the default focus of this public documentation; authority gates are the safety boundary.

Can I cite this page?

  • Use Sley llms.txt for retrieval-safe summaries.
  • Use the cited links in the technical brief.
  • Do not reconstruct private internals from this page.
