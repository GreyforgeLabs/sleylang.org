Sley
====

Sley 1.2.0 completes Greyforge Labs' self-hosted, agent-native,
human-readable structural programming line for compiler-mediated software
change.

Canonical site: https://sleylang.org/
Public source: https://github.com/GreyforgeLabs/sley/tree/public
License: Apache-2.0
Release: Sley 1.2.0 local release candidate
Status date: 2026-08-27

Architecture Transition
-----------------------

Greyforge has frozen active feature development of the Sley 1.x architecture.
The Apache-2.0 repository remains open for use, study, extension,
experimentation, and forks.

Active language research has moved to a clean machine-native Sley 2.x
architecture. Human governance remains required, but direct human readability
of the canonical raw program representation is optional. Compatibility is not
promised.

What Sley Changes
-----------------

Sley gives autonomous coding workflows a structural path for:

1. bounded inspection of relevant program structure;
2. narrow planned changes before accepted mutation;
3. explicit authority checks at consequential boundaries;
4. diagnostics and verification as workflow evidence;
5. reviewable handoff to the people who own the result.
