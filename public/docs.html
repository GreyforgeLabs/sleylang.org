Technical Brief: Sley is the language AI agents want to speak

Designed by AI for AI, with token savings and evidence-first editing baked into the workflow.

This brief aligns to the public release boundary and connects to the open repository under Apache-2.0.

1. Thesis

Sley is the world's first AI-native programming language for structured software agent workflows. The idea is simple: make language work explicit enough that agents can operate with less churn while humans preserve review control.

Token efficiency

The workflow favors compact structure, narrow slices, and checked change plans instead of full-file churn.

Safety posture

Authority is explicit at language and runtime boundaries, reducing hidden behavior and implicit side effects.

Audit and handoff

Verification and provenance artifacts are central, not optional, for accepted updates.

2. Public model

LayerPublic description

Planned updatesCandidate changes are reviewed before source mutation.
Authority gatesCapability-style checks are explicit and testable.
EvidenceVerified handoff artifacts preserve reason and reproducibility.

3. What is intentionally private

  • Grammar internals and some runtime internals are intentionally excluded from this public surface.
  • Security-sensitive adapter paths and deployment details remain behind explicit release gates.
  • Detailed schema and conformance payload catalogs are available in source-released artifacts.
